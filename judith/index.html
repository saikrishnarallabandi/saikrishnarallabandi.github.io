The talk

Wearing the Agent: From Group Chats to Glasses, at the AI Engineer World's Fair 2026.

It starts muted, because browsers will not autoplay sound. Watch it on YouTube instead if you would rather.

An assistant for one person is a feature. An assistant in a room full of people is a different problem.

Once an agent is in a conversation with other people in it, ordinary assistant questions become questions about those people. Anyone present can try to steer her. She accumulates things she was told in confidence. And an answer that is perfectly correct can still be the wrong thing to say in front of the wrong person.

Group threads

She replies where more than one person can see her, and anyone in the thread can try to redirect her.

Smart glasses

The same agent, speaking only to me. Here she is allowed to start the conversation, because the audience is one person.

Quietly, in the background

Scheduled check-ins, mail, health signals and a job board that keep running while nobody is asking her anything.

Plugins

Judith is not one program. She is a model surrounded by twenty-one small plugins, each responsible for one job and nothing else — one decides whether an action is safe to take, one decides what is worth remembering, one decides whether what she is about to say is fit for a person to see. The ones below carry Sanskrit names, and in each case the name is the job.

jataayu
guard rails

Decides whether an action is safe to take, and stops the dangerous one rather than the alarming sentence.

smriti
memory

Keeps facts along with where each one came from, and can replace or quarantine any that turn out to be wrong.

sakshi
the witness

Writes down every tool, model and turn, so a failure can be traced to the moment it happened.

avastha
state

Carries how I am doing into what she is about to say.

drishti
sight

Shows every run she made, why any of them failed, and offers to run it again.

kavacha
armour

Maps where I am to how careful she should be.

sangraha
the collection

Brings in news, filings and market data, and only ever reads them.

upaya
the remedy

Matches a repeating error to the fix that worked the last time it appeared.

sarathi
the charioteer

Sorts a request into a lane and hands it to a separate session to answer.

The same agent, in a room of one.

On the glasses Judith is allowed to speak first, because only one person can hear her. Everything else is unchanged: gather the context, decide whether this moment is worth interrupting, and send the answer only to the person entitled to it. The rule that governs a group thread is the same rule. The room is what changed.
